# Site Map (v0.2 & v0.4)

This document defines the structural hierarchy and URL paths for the ADDF website.

## Primary Navigation (Header)
- Home (`/`)
- Start Here (`/start-here`)
- Docs (`/docs/framework`)
- Downloads (`/downloads`)

## Secondary Navigation (Footer)
- GitHub Repository
- License
- Changelog

## URL Path Structure

### Core Pages
- `/` — Homepage
- `/start-here` — First-session onboarding guide
- `/downloads` — Starter kit, examples, and prompt catalog downloads

### Documentation (`/docs/*`)
- `/docs/framework` — Overview of the framework
- `/docs/scale-model` — Project, Release, Feature, Sprint, Patch
- `/docs/lifecycle` — The 8-step lifecycle and Sprint loop
- `/docs/modes` — Research, Design, and Develop Modes
- `/docs/project-brain` — Required markdown files
- `/docs/starter-kit` — Structure and usage of the starter kit
- `/docs/prompt-catalog` — Usage of the prompt catalog
- `/docs/examples` — Reference examples (Mini Task Tracker)

### Future Releases
- `/onboarding` — Web onboarding app (v0.4 placeholder)
