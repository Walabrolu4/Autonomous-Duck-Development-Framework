## 1. Documentation Verification
- [ ] `website/README.md` exists and explains the directory's purpose and future tech stack constraints.
- [ ] `docs/site-map.md` exists and includes the Homepage, Start Here, Downloads, and Docs sections.

## 3. Review Gates
- [ ] The human operator has reviewed and approved the site map and page blueprints.
- [ ] The information architecture correctly reflects the v0.2 scope (Public website without backend or user accounts).
