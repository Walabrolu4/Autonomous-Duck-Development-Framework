# Website Directory

This directory houses the source code for the Autonomous Duck Deployment Framework (ADDF) website.

## Architectural Constraints
- **v0.2 Scope:** This directory will initially contain the v0.2 static website.
- **v0.4 Scope:** In the future, the v0.4 web onboarding app will also be hosted here as an interactive client-side application.
- **Static First:** Per Decision 003, the v0.2 website is a purely static site with no server-side rendering, database, or API calls.
- **Framework Selection:** Per Decision 009, the chosen framework (e.g., Astro) must support future interactive client-side components without requiring a rewrite for the v0.4 release.

## Sprint 004 Note
During Sprint 004 (Website Information Architecture), no source code, HTML, CSS, JavaScript, or framework initialization files are created in this directory. Only documentation and planning files are produced.
